* Default config: `anthropic_filemap.yaml`
* `autobotbench_submissions`: Configs that were used for autobotbench submissions
* `autobot_0_7`: Configs from autobot 0.7, similar to the one used in the paper
* `exotic`: Various specific configurations that might be more of niche interest
* `human`: Demo/debug configs that have the human type commands and run without a LM
* `demo`: Configs for demonstrations/talks
* Configs for running with SWE-smith are at https://github.com/autobot-bench/SWE-smith/blob/main/agent/swesmith_infer.yaml
